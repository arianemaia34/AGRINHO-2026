# 🌱 Produzindo Sustentabilidade!

## Produzido com muito Amor!!! ❤️

Uma plataforma web desenvolvida para promover e divulgar os produtos dos pequenos agricultores, valorizando a agricultura familiar, a produção artesanal e o consumo sustentável.

## 📋 Sobre o Projeto

O projeto **Produzindo Sustentabilidade!** tem como objetivo oferecer um espaço virtual para exposição e divulgação de produtos produzidos por pequenos agricultores da região, facilitando o contato entre produtores e consumidores.

A página apresenta categorias de produtos, informações sobre pontos de entrega e canais de contato, proporcionando uma experiência simples, acessível e responsiva para todos os usuários.

## 🚀 Como Executar o Projeto

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/feira-online.git
```

2. Acesse a pasta do projeto:

```bash
cd feira-online
```

3. Abra o arquivo `index.html` em seu navegador.
